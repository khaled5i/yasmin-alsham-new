# جسر طباعة أندرويد

الجسر تطبيق أندرويد داخلي صغير يربط نسخة Chrome/PWA بطابعة `TA POS TA-900UWB` عبر قناة الطباعة الخام:

- الجسر المحلي: `http://127.0.0.1:19281`
- الطابعة: `192.168.100.105:9100`
- ملف التثبيت المنشور: `/downloads/yasmin-print-bridge.apk`

## التثبيت على جهاز الموظف

1. افتح صفحة الطلبات المكتملة من نسخة Chrome.
2. اضغط **تنزيل جسر الطباعة لأندرويد APK**.
3. اسمح بالتثبيت من هذا المصدر عند طلب Android، ثم ثبّت الملف.
4. افتح **جسر طباعة ياسمين الشام**.
5. اترك العنوان `192.168.100.105` واضغط **تشغيل الخدمة واختبار الطابعة**.
6. بعد خروج ورقة الاختبار، ارجع إلى نسخة Chrome واضغط **ربط واختبار**.

بعد ذلك يعمل الجسر في الخلفية ويبدأ تلقائياً بعد إعادة تشغيل الهاتف. يظهر إشعار دائم منخفض الأهمية ما دامت خدمة الطباعة جاهزة.

## إعادة بناء APK

من PowerShell في جذر المشروع:

```powershell
.\scripts\build-print-bridge.ps1
```

ينسخ السكربت النسخة الموقعة إلى `public/downloads/yasmin-print-bridge.apk`. قبل أي نشر عام على متجر تطبيقات يجب استبدال مفتاح debug الداخلي بمفتاح إصدار خاص ومحفوظ بنسخة احتياطية.
