# خطط تجهيز متجر أقمشة ياسمين الشام للبيع

تاريخ الفحص: 19 سبتمبر 2026. هذه حزمة تخطيط فقط؛ لم يتغير كود الموقع أو قاعدة البيانات أو إعدادات الخدمات.

## الملفات وطريقة استخدامها

1. [خطة السلة والمفضلة](01-cart-and-favorites.md): سلمها للمساعد المنفذ كتكليف مستقل.
2. [خطة الدفع الإلكتروني](02-electronic-payments.md): تشمل الطلبات والمخزون والفوترة والاسترداد، وليس زر الدفع فقط.
3. [خطة الفحص الأمني والإصلاح](03-security-audit-and-remediation.md): تحتوي نتائج أولية مثبتة ومسار تحقق وإصلاح واختبارات.
4. [متطلبات السعودية وبوابات الدفع وجاهزية البيع](04-saudi-requirements-and-launch-checklist.md): قائمة أعمال التاجر والصفحات والوظائف اللازمة والمصادر الرسمية.

كل خطة تكرر سياقها وقيودها لتعمل عند تسليمها منفردة. عناوين الملفات والجداول الجديدة الواردة فيها مقترحات تصميم، وليست وصفًا لميزات منفذة.

| الهوية | عنابي وعاجي وذهبي، ومتجر عربي يركز على الجوال | الحفاظ على الهوية وإضافة العربية والإنجليزية للواجهات الجديدة |
| رحلة الشراء | التفاصيل تنشئ رابط واتساب؛ لم أجد رحلة checkout أو تكامل بوابة دفع في المسارات المفحوصة | يلزم إنشاء دورة بيع كاملة |

| السياسات | توجد `/privacy` و`/privacy-policy` و`/terms` و`/terms-of-service`؛ بعضها قديم ويخص التفصيل؛ التذييل يستخدم المسارين الطويلين | توحيد المرجع وإضافة سياسات مخصصة لبيع وشحن الأقمشة |
| الأمان | كشف مفتاح خدمة في الكود، صلاحيات واسعة لجدول المستخدمين في القاعدة الحية، وحاوية صور طلبات عامة | معالجة عاجلة قبل توسيع التسجيل أو إطلاق الدفع |

## ترتيب العمل المقترح

1. تنفيذ الجزء العاجل من الخطة الأمنية: الأسرار، جدول المستخدمين، الملفات الخاصة، واجهات الخدمات المدفوعة، تحديث الحزم.
2. اعتماد قواعد بيع الأقمشة وتجهيز بيانات المنشأة والسياسات. يمكن إعداد ملف التاجر وطلب عرض بوابة أثناء التطوير.
3. تنفيذ السلة والمفضلة. النسخة المحلية للزائر لا تحتاج فتح تسجيل عملاء قبل تأمين الصلاحيات.
4. تنفيذ الطلبات والدفع التجريبي والحجز والمحاسبة والشحن.
5. إعادة الفحص الأمني على الرحلة الجديدة وإتمام قائمة الجاهزية، ثم تفعيل الإنتاج ضمن تكليف إطلاق مستقل.

## قرارات مطلوبة قبل التنفيذ التجاري

- هل القطع ذات 3 و3.5 متر تباع كاملة فقط؟ وما الحد الأدنى وخطوة شراء القماش بالمتر؟ القاعدة الحالية للعرض لا تكفي لإقرار ذلك تجاريًا.
- هل كل لون يمثل SKU مستقلًا؟ ومن مسؤول اعتماد ربط اللون بالمخزون؟
- هل الأسعار الحالية تشمل الضريبة؟ وهل المنشأة مسجلة؟ وما وضع نظام الأستاذ مع الفوترة الإلكترونية؟
- ما مناطق الشحن والتكلفة ومدة التجهيز، وهل يوجد استلام من الفرع؟
- من صاحب صلاحية الاسترداد؟ ومتى يبدأ قص القماش؟
- ما الكيان القانوني والحساب البنكي وبوابة الدفع المختارة؟

هذه القرارات لا تمنع تسليم الخطط، لكنها تمنع اختراع إعدادات مالية أو سياسات ملزمة أثناء التنفيذ.

## نطاق التحقق وحدوده

قراءة للكود وملفات الحزم والترحيلات، واستعلامات قراءة فقط لكتالوج قاعدة Supabase وسياساتها وصلاحياتها وبيانات إعداد الحاويات، وتشغيل Security Advisors، وبحث في المصادر الرسمية. لم أقرأ بيانات العملاء أو صورهم، ولم أنفذ دفعًا أو فاتورة أو استغلالًا أو تعديلًا. لم أجرِ معاينة متصفح أو اختبار اختراق شامل أو فحص تبعيات كامل؛ وصف الشكل مستمد من الكود، ولا يمثل شهادة جودة بصرية أو أمنية. نسخة الإنتاج وإعدادات حمايتها الخارجية لم تُطابق مع الكود المحلي.

المتطلبات المنشورة لا تضمن قبول التاجر؛ القرار النهائي للمزود والبنك وفق التحقق والعقد. يعاد التحقق من المصادر عند التنفيذ.
